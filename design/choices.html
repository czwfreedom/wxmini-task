ChoicesUI.Data 参数 ↔ UI 映射（对齐已有接口 ui/choicesUI.ts）
参数类型说明对应形态
idstring弹窗标识，一个页面可挂多个 Choices 实例—
limitednumber?1=单选：无 Header，底部取消按钮，点单元项即回调 onChoicesDialogItemTap 并关闭；>1=多选：Header（取消 | title | 确认(n)），点确认回调 onChoicesDialogConfirmTap1/2/4 · 3
gridstring?每行展示个数：'2' 横向单元（适合带 desc）/ '3' 纵向单元（默认）/ '4' 纯文本2 · 1/3 · 4
itemsEntity.Option[]avatar? 图标 + name 名称(必有) + desc? 描述；多选时 selected 标记初始选中全部
titlestring?单选：居中标题；多选：Header 中间标题全部
confirmstring?多选确认按钮文案，默认「确认」，自动带选中数 (n)3
tipsstring?items 上方提示；单选居中，多选左对齐（可展示「已选 n/上限」）1 · 3
modalboolean?true=不可取消：无取消按钮/✕，点遮罩不关闭预留
orderedboolean?预留：多选有顺序（角标可显示 1/2/3 序号）预留
· 选中态统一：#F4B942 描边 + #FFFDF8 底 + $gradient 角标（勾或序号），与创建页一致
· 确认按钮联动：onSelectedChanged 回报 selectedIds，确认按钮更新「确认(n)」，0 项时置灰不可点
· 单元布局自适应：grid='2' 自动切横向布局（avatar 左 + name/desc 右）；无 avatar 时自动收窄为文本单元
· 关闭路径：单选 = 点项即关 / 底部取消 / 遮罩；多选 = Header 取消 / 确认 / 遮罩（modal 除外）
