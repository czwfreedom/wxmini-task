3. 动效与视觉设计规范

时间节奏

250ms — 遮罩渐入（ease-out）
350ms — 卡片从底部弹入（cubic-bezier 0.34, 1.56, 0.64, 1）
400ms — 撒花粒子飞出 + 消散（整体持续 1.5s）
150ms — 表情缩放出现
自动关闭 — 3 秒后自动淡出，或点按钮/遮罩关闭

色彩规范

金星 + 卡片强调 — $gradient
完成绿 — $green
冷静蓝（撒花粒子） — $blue
里程碑红 — $red
遮罩层 — rgba(255,245,230,0.96)

撒花粒子

数量 — 普通 15-20 个，全部完成 30-40 个，里程碑 50+ 个
形状 — 圆点 + 四角星（两种交替）
颜色 — 金 #F4B942 / 浅金 #FFD54F / 绿 #81C784 / 蓝 #5B9BD5
运动 — 从中心向四周爆开（半径 120-200px），带轻微旋转 + 淡出
规范 — 使用 CSS animation + 随机 delay/方向，不依赖第三方库

庆祝卡片

宽度 — 260px（占手机宽度约 70%）
圆角 — 24px
底色 — 纯白 #FFF + 金色柔阴影
表情 — 56px 金底圆，表情字号 28px
主文案 — 24px 800 权重，金色 $main
副文案 — 14px 700 权重，深蓝 $blue-dark
里程碑 — 边框 2px #FFD54F，表情底色改为红金渐变
