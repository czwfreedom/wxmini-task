四、交互流程与状态

步骤行为备注
① 点入口点击「✦ 模板」→ 显示 loading → Config.list({ type: 1 }) 拉取失败走现有 abort / toast
② 展示列表底部弹窗列出模板卡片，按 proirity 排序数据为 0 时提示「暂无模板」
③ 选一个点某模板的「选这个」→ 该卡片高亮选中态选中态 = #F4B942 描边 + #FFFDF8 底
④ 预填关闭弹窗 → 跳创建页，Intent 预填 { category, detail, duration }复用 Intent.navigateTo(CreateRoutine, { data })
⑤ 填写保存用户在创建页亲手改成自己的内容 → 保存分类/时长也可改，内容由用户确认
⑥ 刷新保存后 → 广播 RoutineUpdated → 列表刷新复用现有 EventBus 机制
关于模板里有多个任务：
一个模板含 2~3 个任务。点模板后，先预填第一个任务进创建页（提示「1/3」）。
用户保存第一个后，可再次点入口选同一模板，预填第二个（「2/3」）……
或者简化：点模板后，把模板的第一个任务预填，其余任务作为创建页里的"下一步建议"顺延。
本期不自动创建，逐个填写是关键。
