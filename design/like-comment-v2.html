① 互动条：去掉圆角胶囊

参考知乎/微信答案底部条——一排「图标 + 文字」水平铺开，margin-right 分隔，无背景、无边框、无圆角。 点赞与评论各占一项，点击区域为整项（图标+文字）。

② 图标重做（参考知乎 / 微信）

- 点赞：用「大拇指」而非爱心（更贴近知乎「赞同」语义）。未点赞 = #C5C5C5 灰色实心；点赞后 = #F4B942 主色实心，数字同步转金色（#C8853E 文字）。仅用颜色区分前后状态，不加背景。
- 评论：用微信/知乎同款「圆角气泡 + 左下小尾巴」。无评论 = 灰色；有评论 = 金色（与点赞同激活色，保持一致）。
两个图标均 20×20，沿用现有 SVG 扁平描边/实心风格，不引入新色值。

③ 评论区：默认收起，点击展开

评论默认不渲染（省高度、保持卡片清爽）。点评论图标 → 展开评论区（带动画）：
收起态（默认） 互动条仅显示 👍 2 · 💬 3。
评论区不可见。
展开态（点评论后） 评论列表（含相对时间）+ 底部常驻「写评论…」入口（吸底）。
列表再长，输入框也钉在底部始终可见。
再次点评论图标或点遮罩外区域可收起。

评论区布局重做

每条 = 「头像（首字彩色圆底，复用现有 relations 风格，取 $main/$blue/$green）+ 昵称 + 相对时间 + 内容」。 相对时间规则：刚刚 → X 分钟前 → X 小时前 → 昨天 HH:mm → M月D日；本人编辑后追加「· 已编辑」。

自己的评论：编辑 / 删除

仅本人评论右侧出现铅笔 + 垃圾桶小图标（默认浅灰，悬停分别变蓝/红）。 - 编辑：复用现有 DialogUI，输入框回填原内容，保存即更新。
- 删除：复用 DialogUI 危险态（红字「删除后无法恢复」+ 红按钮「确认删除」）。
本人的评论底色用浅金 #FFFDF6 轻微区分。

没有评论时，「写评论」入口在哪？

核心思路：写入口就在展开区里，不依赖评论数量。同一种「吸底常驻」形态，无论有无评论都在同一位置，认知一致。

④ 本次优化：长列表找不到输入点

旧方案把「写评论」放在评论列表末尾，评论一长就被推到屏幕外、看不见。
改为 position:sticky; bottom:0 吸底常驻：展开评论后，输入框始终钉在卡片底部，浏览多长列表都不用翻到底。仅改动这一处，图标 / 评论列表 / 编辑删除全部不动。
另可考虑的替代方案：B 顶部常驻（输入框放列表最上方，一展开即见，但阅读流略反直觉）；C 全局底部输入条（从屏幕最底浮出，最像微信，但需动页面级布局，超出本次范围）。
有评论 列表下方常驻一行「✍️ 写评论…」胶囊输入框（浅灰），点它复用 DialogUI 输入。
无评论（count=0） 点评论图标展开后，列表区显示一句「还没有评论，写下第一条吧 ✍️」，再下方同样是「写评论…」入口。即：评论图标是触发键，展开区里的输入框才是真正的写入口，无论有无评论都在同一位置，认知一致、不会找不到。

⑤ 查看谁赞了我：点 赞 / 评论 → 互动详情（上：赞 · 下：评论）

新增一个底部弹层（复用 heatmap / choices 同款 common_dialog：黑色蒙板 + 顶部把手 + 从下上滑），把「赞」与「评论」集中在一屏，解决原设计缺「谁赞了我」可见入口的问题。
触发 点互动条的「赞」或「评论」任一项都唤起此详情弹层。
点「赞」默认滚动定位到赞区；点「评论」定位到评论区。
蒙板点击 / 关闭 ✕ 收起。
上：赞区（头像 + 昵称） 金色爱心 + 点赞者以「头像 + 昵称」chip 横排换行展示（避免首字母撞脸看不出是谁；头像仍取 $main/$blue/$green 首字彩色圆底，昵称取 $foreground-sub）。
出现「我自己」chip = 我也赞了。
下：评论区 分隔线后复用 ③ 的评论列表（头像 + 昵称 + 相对时间 + 内容）；本人评论可编辑/删除；底部常驻「写评论…」入口（吸底，同 ④）。

赞区多人方案（N 较大时）

赞人数少（≤ 8）直接全部换行铺开；人多则默认折叠，避免弹层被赞区撑爆、挤压评论区：
收起态（默认）
我我自己 朵朵朵妈妈 明小明妈妈 乐乐乐爸爸 安安安 航航航 等 6 人 ▾
规则：最多展示前 6 个 chip，超出折叠为「等 N 人 ▾」按钮（金色文字胶囊）。
展开态（点「等 N 人」） 全部 chip 换行铺满，末尾变「收起 ▴」。赞区高度随人数增长，但弹层本身 max-height:80% 可滚动，评论区始终能滚到。
阈值说明：6 为示意值，实现时可按弹层高度或一行可容纳数微调（建议 6~8）。本人「我自己」始终优先展示在第一个，确保一眼看到「我是否赞了」。 与 ③ 的关系：③ 是卡片内联轻量展开评论；⑤ 是聚合查看（含赞列表）。两者并存——内联满足快速看评论，弹层补齐「谁赞了我」并一次性看全互动。弹层头部带任务图标 + 标题，点 ✕ 或蒙板关闭。
