① 互动条：去掉圆角胶囊

参考知乎/微信答案底部条——一排「图标 + 文字」水平铺开，margin-right 分隔，无背景、无边框、无圆角。 点赞与评论各占一项，点击区域为整项（图标+文字）。

② 图标重做（参考知乎 / 微信）

- 点赞：用「大拇指」而非爱心（更贴近知乎「赞同」语义）。未点赞 = #C5C5C5 灰色实心；点赞后 = #F4B942 主色实心，数字同步转金色（#C8853E 文字）。仅用颜色区分前后状态，不加背景。
- 评论：用微信/知乎同款「圆角气泡 + 左下小尾巴」。无评论 = 灰色；有评论 = 金色（与点赞同激活色，保持一致）。
两个图标均 20×20，沿用现有 SVG 扁平描边/实心风格，不引入新色值。

③ 评论区：默认收起，点击展开

评论默认不渲染（省高度、保持卡片清爽）。点评论图标 → 展开评论区（带动画）：
收起态（默认） 互动条仅显示 👍 2 · 💬 3。
评论区不可见。
展开态（点评论后） 评论列表（含相对时间）+ 底部「写评论…」入口。
再次点评论图标或点遮罩外区域可收起。

评论区布局重做

每条 = 「头像（首字彩色圆底，复用现有 relations 风格，取 $main/$blue/$green）+ 昵称 + 相对时间 + 内容」。 相对时间规则：刚刚 → X 分钟前 → X 小时前 → 昨天 HH:mm → M月D日；本人编辑后追加「· 已编辑」。

自己的评论：编辑 / 删除

仅本人评论右侧出现铅笔 + 垃圾桶小图标（默认浅灰，悬停分别变蓝/红）。 - 编辑：复用现有 DialogUI，输入框回填原内容，保存即更新。
- 删除：复用 DialogUI 危险态（红字「删除后无法恢复」+ 红按钮「确认删除」）。
本人的评论底色用浅金 #FFFDF6 轻微区分。

没有评论时，「写评论」入口在哪？

核心思路：写入口就在展开区里，不依赖评论数量。
有评论 列表下方常驻一行「✍️ 写评论…」胶囊输入框（浅灰），点它复用 DialogUI 输入。
无评论（count=0） 点评论图标展开后，列表区显示一句「还没有评论，写下第一条吧 ✍️」，再下方同样是「写评论…」入口。即：评论图标是触发键，展开区里的输入框才是真正的写入口，无论有无评论都在同一位置，认知一致、不会找不到。
