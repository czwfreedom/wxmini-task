为什么之前的反馈都不尽人意？

之前所有版本（弹窗 / 底部条 / 卡片内嵌 / Hero 庆祝 / 多米诺骨牌）都有一个共同问题： 孩子是被动的"看到者"而非主动的"参与者"。

福格说庆祝的关键是"行为发生那一刻的正向情绪"——它不是一条消息，而是一种身体感受。 弹出来的文字和 emoji 是冷的，因为孩子只是看到了它，没有为它做什么。

下面的三个方案，核心原则是：让孩子在完成的那一刻做一个动作，由这个动作本身产生情绪。

三个方案对应三种"孩子的主动动作"：
V1 — 种下一颗植物（触发了生长动画，这是"我种的"）
V2 — 说一句话录下来（听到了自己的声音，这是"我说的"）
V3 — 看到能力条涨了一点（参与了角色成长，这是"我练的"）

方案 V1：成长花园 🌱

核心动作：每完成一个任务，在日常页底部自动种下代表该分类的植物。
不需要弹窗，不需要文字鼓励。种下的那一瞬间——植物从土里冒出来 + 小星星闪烁——就是庆祝。
一天结束时，花园里长满了今天的成果。看一眼就知道"今天完成了什么"。

设计要点
• 每种分类对应不同植物：📖→🌱、✏️→🌿、💪→🌸、🎮→🍀 等

• 完成瞬间触发植物冒出的动画（0.5s），附带小星星向上飘散

• 每天刷新，新的一天新的花园

• 全部完成后花园出现一只🦋蝴蝶或🌈彩虹，提示"今天完美"

• 历史日的花园也可以回看（但枯萎状态，提醒"过去的美好"）

方案 V2：声音回响 🎙️

核心动作：完成时，孩子对着手机说一句话录下来，说完之后听到自己的声音被回放。
这就是"费曼反馈"本身——但不再是"填一个文字框"，而是"说给自己听"。
说完的那一刻，听到自己的声音："我知道了水为什么从高处流向低处"——这就是庆祝。
因为说话的声调、停顿、语气里带着的是真实的思考，比打出来的文字有体温。

为什么声音比文字更有"庆祝感"？
文字是大脑加工过的产物，声音是身体的直接产物。孩子说"我知道了…"的时候，语气里带着的语气上扬、停顿、重复，这些是文字无法传递的。当他自己听到自己的声音被回放——这是一种自我确认："这是我思考过的，我说出来了，我听到了。" 这就是费曼学习法的本质，也是福格说的"庆祝"。

方案 V3：RPG 能力条 🎮

核心动作：完成一个任务后，Hero 区的属性条像游戏里升级一样涨了一截，跳出"+5 XP"。
这不是"被通知完成了一个任务"，而是"自己培养的角色变强了"。
阅读让"知识力"涨了，运动让"体力值"涨了——孩子不是因为"该做"而做，而是因为想看能力条变满。

三版方案对比

维度🌱 V1 成长花园🎙️ V2 声音回响🎮 V3 RPG 能力条
孩子的动作 完成 → 看到植物冒出来（被动，但视觉强烈） 完成 → 按住说话 → 听到自己的声音（主动） 完成 → 看到能力条增长 → "+5"飘出（被动，但像游戏）
多巴胺来源 收集欲——"想看花园长满"；视觉惊喜——植物冒出动画 自我确认——"这是我说的"；听觉冲击——声音比文字有温度 成长感——"我的角色变强了"；进度条填满的满足感
与"费曼反馈"的关系 独立于反馈——花园是额外的庆祝层 融为一体——录音本身就是反馈，庆祝也藏在录音里 独立于反馈——能力条是进度可视化
持续吸引力 高——每天的植物不一样，全满有彩蛋 中高——每次说的内容不同，新鲜感保持较久 中——如果没有"升级/新等级"，重复看填 bar 会疲劳
开发成本 低——纯 CSS 动画 + 几个 emoji/icon 素材，不依赖外部能力 中——需用 wx.getRecorderManager（微信原生录音 API），有权限获取和文件上传 低中——CSS 进度条动画是简单的，但需要与 stat 数据联动
是否替换现有 UI 不替换——在底部附加一个新区域 替换——把"文字反馈"改成"语音反馈"作为主路径（文字作为备选） 不替换——把 Hero 统计区改造成能力条样式
最佳场景 6 岁以下——小朋友最容易理解"种花" 小学低年级——开始能表达、乐于开口 小学中高年级——能理解 RPG 概念、追求数据
这三者不是"三选一"的关系。

最理想的组合是：
• V2 作为完成反馈的主交互——用语音替代文字反馈，把"说"变成庆祝
• V1 作为长期的额外动机层——花园是每日积累的"视觉日记"，吸引每天回来看看
• V3 作为每周/每月的回顾——能力条不适合每天看（会腻），但在周报里展示本周能力成长图很适合

如果只能先做一个：V2。
因为它同时解决了两个问题：① 费曼反馈太难（打字 → 说话）② 完成没有庆祝（录音后的回放就是庆祝）。一举两得。
