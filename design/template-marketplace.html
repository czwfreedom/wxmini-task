什么是「习惯模板市场」？

🤔 问题

妈妈 A 第一次打开小程序，看到空白的任务页。
她不知道要给孩子设置什么任务——
"阅读？多久？练字？什么频率？"

于是困惑 → 随便点了几下 → 离开了 → 再也没回来。

💡 解法 — 模板市场

就像一个"任务菜单商店"。
其他妈妈已经做好的任务方案陈列在里面，
按年龄 / 类型 / 热度排序。

新手妈妈进来 → 浏览 → 看中一个 → 一键复制 →
孩子立刻有了 3-5 个任务 → 开始打卡。

🔄 为什么能裂变

有经验的妈妈把自己训练出来的任务方案
"上架"到模板市场。

她会分享一张"我的模板被 128 位妈妈使用"
的海报到妈妈群。

这不是广告，这是育儿经验的可复制化。

核心逻辑：把"给孩子定任务"这个冷启动难题，从每个人自己想 → 变成可以从别人的方案里挑。 同时给了有经验妈妈一个"输出"的出口——她们的模板被人使用，本身就是一种认可。

这张海报为什么能传播：
• "128 位妈妈使用"是强社交证明——不是广告，是口碑
• "来自小明妈妈"是个人品牌——育儿经验被认可的满足感
• 色彩克制，不像商业广告（降低防御心理）
• "一键导入"降低行动门槛
• 不直接宣传小程序，而是宣传"这份育儿方案"

入口位置展示方式触发时机

分享卡片 在已有的"邀请伙伴围观"分享之外，增加"分享我的育儿方案"选项 点击分享按钮时二选一

规则与数据

📋 模板规则

• 一个模板 = 一组任务（2-5 个）
• 包含名称、适用年龄、分类标签
• 可选推荐语（发布者自己的使用感受）
• 导入时会保留任务名 + 分类 + 时长，但不会带历史数据
• 每个模板独立计数"使用人数"
• 发布者可以编辑/下架自己的模板

🔢 数据需求

新增服务 server/template.ts：
• Template.list(tag, age, page) — 浏览市场
• Template.create(data) — 发布模板
• Template.import(tplId) — 导入（调用 Routine.create 批量）
• Template.stat(tplId) — 使用人数 + 趋势

模板数据结构：
{ id, userId, name, desc?, ageRange?, tasks: [{name,category,duration}], useCount, createTime }

🔄 导入后的体验

• 一键导入 = 后台调用 Routine.create 批量创建
• 导入后弹出轻提示「已添加 3 个任务，去调整→」
• 导入的任务默认状态为 Pending（待完成）
• 可以在"今日日常"中删除/编辑导入的任务
• 导入某个模板后，该模板的使用人数 + 1
• 同一用户可以重复导入同一个模板（如换一天想再用）
