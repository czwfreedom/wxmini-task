微信同声传译插件（WechatSI）

插件 ID wx069ba97219f66d99，微信官方自研。录音 + 实时语音识别 + 翻译 + 语音合成四合一， 不需要任何后端 ASR 服务，全部能力在微信侧完成。

对我们最有用的能力：语音输入（ASR）

插件提供 RecordRecognitionManager——它比原生 RecorderManager 多了一层实时语音转文字。 孩子按住说话的同时，识别结果会逐句流式返回，松手后拿到最终全文。

能力说明限制与我们需求的匹配
录音 + 识别 调用 start({duration, lang}) 开始录音并进行实时语音转文字 最长 60s 完美——孩子一句话 15-30s 足够
流式结果 onRecognize(res) 每识别出一句就回调一次，res.result 是当前累计文本 — 完美——可以在录音过程中实时显示文字，体验极好
最终结果 onStop({ tempFilePath, result, duration }) —— 拿到录音文件路径 + 完整识别文字 + 时长 — 一举三得——音频 + 文字 + 时长都在一个回调里
语言支持 zh_CN（默认）/ en_US / zh_HK / sichuanhua 4 种方言 默认 zh_CN 即可
调用配额 250 次/分钟，30,000 次/天 按小程序计 远超需求——日活 1000 人每人说 30 句才刚够

核心优势：不需要后端 ASR 服务。
之前的分析说需要"后端接入语音识别服务"，现在不需要了——
微信把录音 + 识别合在一起，一次 API 调用就拿到录音文件和识别文字。
这对我们的价值：开发成本砍半，而且微信的 ASR 引擎对小朋友的中文识别准确率远高于通用引擎。

接入方式（只需三步）

第一步：在 app.json 中声明插件

// miniprogram/app.json
{
  "plugins": {
    "WechatSI": {
      "version": "0.3.6",
      "provider": "wx069ba97219f66d99"
    }
  }
}

第二步：在页面中获取管理器

const plugin = requirePlugin("WechatSI");
const manager = plugin.getRecordRecognitionManager();

第三步：绑定事件 + 开始录音

// 流式识别——录音过程中实时返回文字
manager.onRecognize = (res) => {
  // res.result: 当前累计识别文本，用于实时显示
  this.setData({ transcript: res.result });
};

// 录音过程中出错
manager.onError = (res) => {
  // res.retcode + res.msg，常见错误：无网络、权限被拒
  console.error(res);
};

// 松手停止——拿到最终文字 + 录音文件
manager.onStop = (res) => {
  // res.result: 最终识别文字（简体中文）
  // res.tempFilePath: 录音文件的临时路径（mp3）
  // res.duration: 录音时长（毫秒）

  // 保存到任务反馈
  const remark = res.result;
  const audioPath = res.tempFilePath;
  // → Routine.update({ id, remark }) 直接存文字
};

对 V2 "声音回响"方案的直接收益：
① 录音过程中可以实时显示识别文字（onRecognize 流式回调）——孩子看着自己的话变成字，本身就是一种即时反馈
② 不需要后端 ASR 服务——文字直接从插件获取，保存到 remark 字段即可
③ 音频文件路径在 tempFilePath 中——如果想保留原声播放，还是需要上传（但 MVP 可以只保留文字，不上传音频）
④ 微信的中文儿童语音识别经过大量训练，准确率比通用方案高

更新后的 MVP 方案

仅文字模式（最简 MVP）

① WechatSI 录音 + 识别
② 拿到 res.result
③ 存储到 remark 字段
④ 卡片上展示文字

不需要后端任何改动。
预估前端工作量：1-2 天。

文字 + 音频模式（完整版）

① WechatSI 录音 + 识别
② res.result → 存 remark
③ res.tempFilePath → uploadFile 上传 → 返回 CDN URL → 存 mediaRemark
④ 卡片上：文字 + ▶️ 播放按钮

需要后端新增上传接口。
预估算上前端共 4-5 天。

进度：实时文字 + 声波

录音过程中利用两件事：
① onRecognize → 实时滚动显示识别中的文字
② RecorderManager.onFrameRecorded → 同时获取音量帧 → 驱动声波跳动

两个 API 可以共存。
WechatSI 底层也用了 RecorderManager，可以同时绑。

需要注意的点：
① WechatSI 插件需要在小程序后台先添加（设置 → 第三方服务 → 插件管理 → 搜索 "微信同声传译" 添加）
② 插件版本号建议锁定（如 0.3.6），不要用 latest
③ 基础库版本要求 ≥ 1.9.94（当前小程序配置已远超此版本）
④ 首次使用会弹出麦克风授权，需要在授权被拒时引导去设置页
⑤ 录音过程中如果微信切后台或被电话打断，onError 会触发，需要有降级提示
⑥ 关键：WechatSI 的 onStop 回调拿到的文字已经是最终版，识别准确率很高，不需要再做后处理
