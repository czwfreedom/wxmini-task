3. 热力图视觉与数据规范

A. 颜色语义

状态颜色圆点样式触发条件
未打卡（无任务） #F0F0F0空心浅灰当天没有创建任何任务
部分完成 #FFE08A金色底，白色数字有任务已完成，但有未完成的
全部完成 #81C784绿色底，白色数字当天所有任务均已完成
未完成（过期） #FEE4E4浅红底，红色「✕」当天有任务但一个都没完成（已过期）
今天—金色双层描边高亮今日日期，指导当前焦点
未来日期—不渲染 content，占位不可点击，轻浅显示（opacity 0.35）

B. 交互规则

动作行为
点击 Hero 区的日历图标 / 连续天数底部滑出热力图面板（遮罩 + 从底部向上 slide-up，300ms cubic-bezier）
点击遮罩或下拉手柄面板滑回关闭
左右箭头切换月份切换热力图网格数据（只展示有历史数据的月份，最大回溯 12 个月）
点击过去某个日期圆点关闭面板，调用 router.navigateTo 跳转到该日任务列表（只读模式，无操作按钮）
点击今天圆点关闭面板，等同于留在当前页面
点击未来日期 / 空白占位无响应

C. 数据来源

接口：现有 Routine.stat 返回 Stat { total, finished, days?, rowDays? } 需要扩展为按日期聚合的数组 StatRecord[] { date, total, finished }， 或前端在获取列表时本地计算。 热力图只需要 date + status(全部完成/部分完成/未完成)， 一次批量获取近 12 个月的数据（最多 365 条，数据量极小）。

D. 动效规范

面板进出

进入 — translateY(100%) → 0, 300ms, ease-out
退出 — translateY(0) → 100%, 250ms, ease-in
遮罩 — opacity 0 → 0.3, 同步 300ms
手柄 — 哑光灰 #D9，高度 5px，宽 36px，表明可拖拽

圆点高亮

今天描边动画 — 金色描边从 3px 脉动到 6px（2s 循环）
悬停态 — 圆点 scale(1.15) + 轻微发光 (150ms)
历史日点击 — 圆点短暂亮起 (scale 1.2 → 1.0, 200ms) 后关闭面板

E. 布局数值

圆点参数

圆点直径 — 28px（375px 宽设备下），跟随屏幕比例缩放
列间距 — flex 均分，约 4-6px gap（或使用 calc 计算）
行间距 — aspect-ratio: 1，正方形格子自然形成行列间距
数字字号 — 10px（圆点内日期数字）

入口参数

日历图标尺寸 — 56×40px，圆角 12px
连续天数显示 — 18px 粗体 + "天" 字 10px
入口气泡色 — $gradient，柔阴影
可选 — 如果连续天数已达里程碑（7/30/100），图标旁加 ✨ 小标记
