为什么是妈妈？

妈妈是育儿消费决策的核心。她们在微信群高度活跃（班级群 / 妈妈群 / 兴趣群）， 有强烈的"晒娃 + 互助 + 焦虑缓解"内容需求。

让妈妈主动传播的三个引擎： 炫耀（孩子进步可视化）、 互助（习惯养成经验分享）、 组队（拉其他妈妈一起，互相督促）。

裂变回路核心模型

一条典型的妈妈传播链路：

孩子完成打卡 → 生成成长周报 → 妈妈分享到群
↓
其他妈妈看到 → 点击卡片进入 → 创建孩子任务
每完成一次"生成→分享→进入→创建"，就多一个活跃用户。多次循环产生指数增长。

六大裂变策略（按优先级排列）

P0 📊

1. 成长周报

自动生成，自动想分享。

每周末生成一张精美卡片：孩子本周完成了哪些任务、哪个做得最好、 一句来自费曼反馈的金句引用（如"我知道了水为什么从高处流向低处"）、 对比上周的进步、连续打卡天数。

妈妈看到的是孩子一周的成果浓缩，几乎一定会保存并分享到朋友圈/群。
P0 👩‍👩‍👧

2. 组队挑战

裂变核心引擎，类似"拼团"但用于习惯养成。

妈妈发起一个 3-5 人小队挑战（如"7天阅读挑战"）， 生成邀请卡片发到妈妈群。其他妈妈点卡加入，各自给孩子创建阅读任务。 小队看板显示所有人的进度和完成情况。

本质是社交契约：拉人进来 = 帮朋友的孩子养成习惯，拒绝成本极高。
P0 📋

3. 习惯模板市场

新手妈妈不知道"该给孩子定什么任务"。

提供一个模板库（按年龄/类型分类），每个模板一套预制任务。 妈妈可以把自己的定制模板"发布到模板市场"， 其他妈妈一键导入，同时看到"本模板已被 128 位家长使用"。

模板 = 育儿经验的实体化。分享模板带来的社交货币比分享任务更高。
P1 🏅

4. 里程碑海报

每个关键节点生成一张可分享的海报：
连续 7 天 · 30 天 · 100 天
累计完成 50 · 100 · 500 个任务
单类任务突破（阅读 30 天 / 练字 50 页）

海报上包含孩子的「成就数据」+ 一句总结 + 小程序二维码。 妈妈在纪念日式的节点上分享，传播转化率最高。
P1 📖

5. 费曼金句集

孩子完成任务的"费曼反馈"是天然的内容资产。

自动收集孩子写过的最好的反馈，生成"小明的知识成长语录"。 比如阅读笔记：「我最喜欢孙悟空，因为他从不放弃」， 配上精美的卡片排版。

这种内容既有教育意义又有情感温度，妈妈分享的动机极强——它不是广告，是孩子的成长印记。
P2 🎁

6. 邀请奖励

轻量物质激励 + 精神激励结合：
每成功邀请一位妈妈，解锁一个新主题皮肤 / 贴纸 / 勋章。 注意避免做成"拉人头"的感觉， 奖励物是孩子喜欢的（可爱主题、趣味音效）， 而非现金红包（会降低调性）。

让孩子说"妈妈，我想换个海洋主题，你帮我邀请阿姨吧"——这才是最强驱动力。

🎯 核心裂变功能：组队挑战（详细设计）

这是六个策略中爆发力最强的一个。因为它复用微信群已有的社交关系， 且每一步都有自然的分享节点。

A. 挑战类型

类型示例说明
主题挑战 「7天阅读挑战」「14天运动挑战」「30天练字挑战」 单类别聚焦，适合拉刚需妈妈。系统预制模板 + 妈妈可自定义名称和天数。
全能挑战 「学霸一周挑战」：每天完成阅读+作业+练字 多任务组合，适合已有使用经验的妈妈。模板市场提供这类组合。
亲子挑战 「妈妈也运动」：孩子运动 + 妈妈也每天走 8000 步 妈妈参与进来，社交属性翻倍。妈妈自己也是"队员"。

B. 完整流程

发起 → 邀请 → 加入 → 打卡 → 互看 → 结算 → 分享

步骤操作裂变节点
① 发起妈妈在挑战中心选择一个挑战模板（或自定义），系统自动给孩子创建对应任务。—
② 邀请生成挑战邀请卡片（包含挑战名称+发起人+已加入人数+二维码），分享到微信群。🧨 第一次传播：群内曝光
③ 加入其他妈妈点击卡片，进入小程序，自动加入挑战，系统也帮她的孩子创建同样任务。🧨 无门槛转化：点即创建
④ 打卡每天孩子完成任务后，挑战看板更新每个人的完成状态（仅显示完成/未完成，不暴露具体内容）。—
⑤ 互看群内妈妈可以看挑战看板——"小明已完成 ✅ / 小芳还没做 ⏳"。自然产生群内讨论。🧨 第二次传播：群内讨论带量
⑥ 结算挑战结束时生成"挑战报告"：全员完成率、谁是坚持冠军、最晚打卡记录等趣味数据。🧨 第三次传播：报告截图到群
⑦ 二次分享结算后弹出"发起新一轮挑战"引导，并展示"最近热门的挑战"供参考。🧨 持续的传播循环

C. 邀请卡设计要点

邀请卡是这个功能裂变胜负的关键。它不是广告，而是"帮朋友的孩子变好"的邀请函。
📚
7天阅读挑战
发起人：小明妈妈
已加入 2 / 5 人
点击加入挑战

设计要点：
• 突出挑战主题 + 天数，信息一目了然
• 展示"已加入人数"，制造从众效应
• 文案体现邀请者的身份（"小明妈妈"），增加信任
• 点击即加入（如果首次使用，先引导创建昵称 + 自动创建任务）
• 不要做成"广告"，而是一张"小队召集令"

🖼️ 为妈妈定制的海报体系

所有海报设计原则：不要品牌露出过度（小程序名小字即可）， 重点是孩子的成长数据和内容，妈妈分享时感到的是"晒娃"而非"推广"。

海报矩阵

触发时机海报主题核心内容妈妈分享理由
每周日晚 8 点 「小明的一周成长报告」 完成 5/7 天 + 最爱阅读 + 一句金句 "看看我家孩子这周的进步"
连续打卡 7/30/100 天 「坚持 × 天的力量」 数字 + 变化（读了 X 本书 / 写了 X 页字） "坚持真的能看到变化"
每完成一次组队挑战 「我们做到了！」 小队全员打卡记录 + 趣味数据 "和姐妹们一起坚持下来了"
开学季 / 寒暑假 「小明的暑假成长记」 假期累计数据 + 最高光的费曼反馈 "一个暑假的变化"
妈妈自定义 「分享我的育儿利器」 小程序卡片 + 个人使用数据 "这个小程序真好用，推荐给大家"

📐 优先级与投入产出评估

功能裂变强度开发成本优先级理由
组队挑战 ⭐⭐⭐⭐⭐ 中高 P0 裂变引擎，一个挑战 = 3-5 个新用户，且有多次传播节点
成长周报 ⭐⭐⭐⭐⭐ 低 P0 自动触发、低开发量、高分享率，ROI 最高
里程碑海报 ⭐⭐⭐⭐ 低 P0 在已有数据基础上多几张海报模板，边际成本极低
习惯模板市场 ⭐⭐⭐⭐ 中 P1 解决冷启动内容，但需要运营维护模板质量
费曼金句集 ⭐⭐⭐ 低 P1 自然内容资产，自动生成，但依赖孩子的长篇反馈
邀请奖励 ⭐⭐⭐ 中 P2 锦上添花，调性需控制，避免变成"拉人头"

建议首批落地（P0 三项）

这三项有协同效应：组队挑战带来新用户 → 成长周报让老用户持续分享 → 里程碑海报在关键节点放大传播。

三管齐下，可在 2-3 周内完成开发，用一个版本打出裂变闭环。
