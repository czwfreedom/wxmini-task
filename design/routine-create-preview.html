v6 设计变更（★ 标记为本版新增）
计划时长 · 选项调整：10分钟 / 25分钟（标准番茄钟）/ 30 / 45 / 1小时 · 其他（3列网格，其他在第二行末尾）。25分钟替换了之前的15/20分钟。
计划时长 · 自定义输入："其他"为虚线入口（与时间"其他"风格一致）。点击后在 grid 下方展示 <input type="number" />，带"分钟"后缀，手机键盘弹起为数字键盘。
计划时间 · 原生 picker："其他 ›" 点击触发 <picker mode="time" />，弹出微信原生时间选择器（时/分双列滚轮）。选择后回填为选中态 chip。
控件均为微信原生：时长用 <input type="number" />（数字键盘）、时间用 <picker mode="time" />（原生滚轮），无需自绘或第三方组件。
数据流要点：自定义时长 → adapter 新增 customMinutes 状态字段，input bindinput 实时更新。自定义时间 → picker bindchange 回调拿到 HH:mm 字符串，存入 timeValue。
保留 v5 逻辑：常用/更多互斥选中、横排 pill、CTA 流内不遮挡、全局压缩不变。
